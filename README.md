# Tema 2 – Integrare API și AI

## Descriere
Această aplicație web afișează o glumă aleatorie folosind **Official Joke API**.  
Scopul proiectului este de a demonstra integrarea unui API extern, utilizarea
JavaScript modern (async/await), gestionarea erorilor și un flux de lucru corect
folosind Git și GitHub.

Aplicația a fost realizată ca parte a **Temei 2 – Integrare API și managementul
versiunilor asistat de AI**.

---

## API utilizat
**Official Joke API**  
Endpoint:  
https://official-joke-api.appspot.com/random_joke

API-ul returnează:
- întrebarea glumei (setup)
- răspunsul (punchline)
- id-ul glumei
- tipul glumei

---

## Funcționalități
- Afișarea dinamică a unei glume random
- Buton pentru generarea unei noi glume
- Tabel cu detalii despre glumă (ID, Tip)
- Element vizual pentru interfață
- Tratarea erorilor folosind try/catch
- Log-uri în consola browser-ului pentru debugging

---

## Tehnologii folosite
- HTML
- CSS
- JavaScript (async/await, fetch API)
- Git & GitHub

---

## Utilizare
1. Deschide aplicația în browser
2. Apasă butonul **„Generează glumă”**
3. Gluma și detaliile acesteia vor fi afișate automat
